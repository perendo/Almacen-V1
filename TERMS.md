# Términos y Condiciones de Uso

## 1. Aceptación de los términos

Al acceder y utilizar el sistema WMS — Módulo de Gestión de Almacén e Inventario ("el Sistema"), usted acepta quedar vinculado por estos Términos y Condiciones de Uso, así como por la Política de Privacidad y el Aviso Legal asociados.

El Sistema se distribuye bajo licencia MIT (ver archivo `LICENSE`). Se permite el uso, copia, modificación, fusión, publicación, distribución, sublicencia y venta de copias del Software, siempre que se incluya el aviso de copyright y el permiso correspondiente.

## 3. Uso permitido

El Sistema está destinado a la gestión de almacenes e inventarios, incluyendo multitenencia, trazabilidad por lotes y números de serie, control de stock, alertas, informes y auditoría. El usuario se compromete a no utilizar el Sistema para actividades ilegales, fraudulentas o que vulneren derechos de terceros.

Los autores y titulares de derechos no serán responsables de daños directos, indirectos, incidentales, especiales, emergentes o punitivos, incluyendo pérdida de datos, interrupción del negocio o fallos de trazabilidad, derivados del uso o la imposibilidad de usar el Sistema.

## 5. Privacidad y protección de datos

El Sistema trata datos de inventario, usuarios y operaciones de almacén. Consulte la Política de Privacidad para información sobre el tratamiento de datos personales conforme a RGPD/LOPDGDD.

## 6. Auditoría y trazabilidad

El Sistema incluye un módulo de auditoría (`audit_logs`) que registra operaciones críticas. El administrador del Sistema es responsable de configurar, revisar y conservar dichos registros conforme a las normativas aplicables.
